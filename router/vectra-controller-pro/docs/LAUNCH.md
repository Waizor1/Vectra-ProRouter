# Запуск роутеров Vectra в массы

Что нужно сделать, чтобы роутер с vctl ушёл к обычным клиентам, и в каком
порядке. Каждый шаг — с проверкой и откатом. Порядок важен: следующий шаг
начинается, только когда предыдущий доказан.

## Что клиент получает (vctl 0.5.0 + мастер из «Unreleased»)

- **Мастер настройки** при первом входе на роутер (LuCI открывается сразу на
  Vectra). Мастер проверяет три вещи: работает ли интернет, выжат ли максимум
  из Wi-Fi и есть ли на роутере подписка.
  1. Интернет. Роутер подключается сам, мастер только проверяет и
     подсказывает, если нет кабеля или интернет не появился за минуту.
  2. Wi-Fi, оба диапазона сразу, одной кнопкой (после предупреждения о
     перезапуске Wi-Fi). Роутер слушает эфир только в этот момент, ставит на
     2,4 и 5 ГГц самые свободные фиксированные каналы (без DFS, с учётом
     ширины канала), максимальную мощность и страну PA; автовыбор канала не
     включается. После перезапуска роутер сам проверяет, что сети поднялись,
     и если рабочий диапазон не поднялся — возвращает прежние настройки и
     говорит об этом. Экран результата показывает по диапазону канал, эфир
     вокруг и мощность. Имя и пароль менять не обязательно; открытой сети
     задаётся имя Vectra-XXXX и сгенерированный пароль с QR для телефона.
     Роутеры с 6 ГГц мастер только переименовывает. Шаг можно пропустить.
  3. Привязка к аккаунту Vectra по QR / коду / ссылке в Telegram; шаг ждёт,
     пока подписка реально приедет на роутер.
  4. Сервер. «Авто» (рекомендуем: сам ведёт через мосты в России к самому
     быстрому выходу за рубежом) или конкретная страна из подписки. Редкие
     варианты (протокол, «прямой», белые списки) свёрнуты.

  После мастера — короткое знакомство с главным экраном из четырёх подсказок;
  его можно пропустить и повторить кнопкой «Как это работает». Пароль от
  роутера мастер не задаёт: его просит баннер LuCI. Уже настроенным роутерам
  мастер не показывается.
- **Простой экран**: работает ли VPN — простыми словами и только по фактам;
  сервер («Авто» или страна) со списком; «Мои сайты» (без VPN / через VPN,
  поверх правил провайдера); «Если что-то не открывается»: перезапуск, другой
  сервер, отчёт в поддержку одной кнопкой.
- **Pro** для тех, кто разбирается: балансировщики, узлы, пины, журнал.
- **Замок оператора**: у клиентских роутеров Pro можно выключить из панели
  или `uci set vectra-controller-pro.main.ui_lock=1`; роутер сам отказывает
  Pro-методам.

## Подготовка новых коробок

- Прошивка с предустановленным пакетом `vectra-controller-pro` и LuCI.
- Подключение к провайдеру выставляется при подготовке роутера (по умолчанию
  автоматическое); мастер клиенту этих настроек не показывает и не меняет.
- Wi-Fi по умолчанию и пароль от роутера на карточке в коробке — иначе первый
  вход только по кабелю (у чистого OpenWrt Wi-Fi выключен, пароля нет).
- Страна Wi-Fi PA (Панама) даёт наибольшую разрешённую мощность — это решение
  владельца. В некоторых странах такая мощность выше допустимой.
- На карточке: «Подключите кабель провайдера в WAN → подключитесь к Wi-Fi с
  карточки → откройте 192.168.1.1 → следуйте мастеру».
- Бот поддержки на случай, когда роутер ещё ни разу не был в сети:
  `uci set vectra-controller-pro.main.support_bot=<бот Vectra без @>` в образе
  прошивки — мастер покажет «Написать в Vectra» и без связи с панелью.

## Критерии отката волны

Любое из: больше 2 % роутеров волны не выходят на связь с панелью 30 мин;
у роутеров волны вердикт «Не работает» / «Трафик идёт мимо VPN» дольше 10 мин;
жалобы, которых простой экран не объясняет. Откат: канал обновления на
предыдущую версию; на роутере — `/etc/init.d/vectra-controller-pro stop &&
disable` возвращает прежний стек (см. `docs/CANARY.md`).

## Памятка поддержке: что видит клиент и что делать

Клиент присылает отчёт кнопкой «Скопировать отчёт» — в нём состояние, сервер,
модель, версии, связь с панелью, память и все непройденные проверки с их id.
Паролей и ключей в отчёте нет.

| клиент видит | значит | что делать |
|---|---|---|
| Всё работает | VPN работает, узлы проверены | если сайт не открывается — «Мои сайты» (без VPN для банков, через VPN для заблокированного) или другой сервер |
| Работает через запасные серверы | основные узлы сервера мертвы, трафик в резерве | другой сервер; проверить узлы провайдера |
| Серверы не отвечают / Интернет идёт без VPN | у основного трафика нет живого пути / путь ведёт в DIRECT | другой сервер; проверить подписку |
| Трафик идёт мимо VPN | перехват сломан при работающем xray (`no_leak` fail, `escaped`) | перезагрузка роутера; если повторяется — Pro → Диагностика, эскалация |
| Интернет не работает | то же при включённом kill switch | то же |
| Не работает (xray не запущен) | xray упал | «Перезапустить VPN»; если не помогает — журнал в Pro |
| Роутер не подключён к Vectra | роутер не привязан к аккаунту (или владелец его отвязал) | кнопка «Подключить к Vectra» → QR / код в приложении Vectra |
| Получаем настройки VPN | аккаунт подтверждён, конфиг ещё едет | подождать минуту; дольше 10 минут — проверить в панели job `apply_xray_config` |
| Роутер ещё не настроен | привязан, но конфигурации нет | проверить роутер в панели: одобрен ли, есть ли ревизия |
| Мешает другая программа | работает PassWall | выключить старый стек |
| Vectra не отвечает | не установлен или не запущен контроллер | перезагрузка, затем переустановка пакета |
